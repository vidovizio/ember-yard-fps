EMBER YARD is an original round-based tactical FPS set in a rain-slick freight terminal at dusk. EMBER attackers plant the Ember charge at the crane pad or fuel depot while HARBOR defenders hold the yard. Features five-on-five rounds, original freight-yard lanes and plant sites, waypoint-driven bots, a buy-phase economy, hitscan weapons, frag grenades, procedural audio, rain, and deterministic `?shot=start|play|end&seed=N` render modes.

## Controls

- **W A S D** move, **mouse** aim and fire
- **Space** jump, **Ctrl** or **C** crouch
- **B** buy during prep; click an item to purchase
- **R** reload, **1** knife, **2** sidearm, **3** Longbow-9, **4** Osprey/Vandal Prime
- **G** throw a bought Shard; **E** hold to arm the charge at a site
- **Right mouse** scope with Osprey; **Esc** release pointer lock
- Click the yard to capture the mouse and deploy

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
